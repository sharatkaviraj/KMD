# Training sheets — one page per role (Hindi + English)

Go-live Phase G (plan §11 "Training", critique1 B20). About 30 minutes per
role, T-7 to T-2, on One with a **test account** under `TEST-2026-27` — never
on a real student. Print each page; the trainer and the person sign the
bottom line, and the signed sheet is that role's acceptance for sign-off
(plan §12.4). Every page ends with the same help line and the same fallback.
