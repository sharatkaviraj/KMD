# A whole school day, run by agents — 14–15 October 2026

Raj asked for one complete school day to be operated end to end by agents playing
the school's real staff, for the bugs, misalignments and slow screens they hit to
be found from each person's point of view, and for developer agents to fix them.
This is the record. Raw reports, scripts and 462 screenshots stay outside the
repository (`.dayrun/`, git-excluded) because they carry replica names.

## How it was run

- **Data.** schoolfees-dev's de-identified replica (585 active children, 19
  classes, published timetable of 2,076 slots, fee data to 11 Oct). 14 Oct was a
  clean day: registers opened by the morning job and empty, no absences, no
  receipts. No extra seeding was needed; every write below went through the app.
- **App.** A production build of `main` on `localhost:3300`, signed in per role
  with the passwordless QA accounts, driven by Playwright scripts the agents wrote
  (`.dayrun/lib.mjs`). Phone roles at 390 px; desk roles at 1366 px.
- **Six role agents in parallel**, each told who the person really is (Hindi-first
  teachers on cheap Android phones; an accountant with a queue of parents holding
  cash; a principal who wants to know in ten seconds what is wrong):

  | Agent | Accounts | Day |
  |---|---|---|
  | Class teacher | `teacher` | register with absences and a half day, late-arrival correction, offline save, marks, notes, leave, cover duty |
  | Subject teacher | `teacher2`, `teacherWithoutClasses` | own register, class boundaries, marks for another class, cover acknowledge, an empty new joiner |
  | Principal | `admin`, `viewOnly` | teacher sick at 7:40 → cover, Today, attendance on behalf, Needs you, students, an admission, staff, a staff notice, search |
  | Fee desk | `accountant`, `office`, `feeCollector` | cash, partial UPI, cheque, concession, bad amounts, double-click, wrong entry, day close, dues calls, reminders preview, reports |
  | Coordinators | `academic`, `exam` | attendance chase, cover, progress, timetable, calendar; marks tracker, date sheet, results, report cards, exports |
  | Performance | all | TTFB/LCP/JS per route, throttled 4G + 4× CPU, prefetch census, query timings, bundles |

- **Five developer agents**, each in its own worktree with file ownership so
  they could not collide: speed (#91), teacher screens (#90), fee desk (#88),
  cover/admin/search (#87), exams/report cards (#89). Each opened a PR, CI was the
  full check, and the lead reviewed and merged in order.
- **Two verifier agents** then re-ran the original repro steps on a fresh build
  of the merged `main`; what they found still wrong is #92.

Caveat on timings: during the role run five headless browsers saturated the
laptop (100 % CPU, under 1 GB free) and the dev database; absolute numbers from
that window are inflated. Quiet-machine and verification numbers are below.

## Speed

Root cause, from the performance agent: the server waits on the database, and
pages made too many calls — no missing index was found.

- Admin Today ran the class board 3× and Needs you 2× per load (~70 PostgREST
  calls) → once each (D-281).
- Every page shipped 67 KB gzip of Supabase client for the session-expired sheet
  → loaded when idle.
- Teacher Today read the whole 2,076-slot timetable twice for six day names;
  calendar, bells, timetable and subjects were re-read on every screen → cached
  across requests, busted by the writes that change them (D-281).
- Tabs now start loading on touch; the register is prefetched on a teacher's
  Today between 08:00 and 10:30.

## Still open, and what needs the school

- **Concessions (needs a decision).** The desk refuses them now. Re-enabling
  needs the fee app's balance view to read `receipt_adjustments` discounts (a fee
  object, so a fee-app change and a live migration), or a different path (a
  discount on the student's fee record, which the view does read).
- **Late fee on a brand-new admission.** A child admitted in October is charged
  ₹1,000 late fee on each installment that fell due before they joined. Fee-app
  rule; worth the school's view.
- **Half marks on whole-mark papers** in the replica block three papers until
  someone rounds them; the exam office should decide the rule once.
- Not built: family (sibling) single receipt, one-tap receipt print, leave-vs-cover
  clash warning, retry for a failed parent-alert queue, Devanagari search, a
  client-side Dues call sheet, the remaining duplicate `<main>` landmarks and
  English strings on Cheques.
- Never run: physical phones, real network in a village, real staff. The agents
  are a proxy for the first trial, not a replacement for it.
