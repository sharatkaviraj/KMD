## Read this first: what went wrong with the run itself

- **20 October 2026 is Dussehra.** The calendar is right, and the run was planned on a holiday. Teachers could not take today's register, so they marked Monday 19 October instead (unmarked, a real past day). Holiday findings are recalibrated: "no school today" is not a bug; the bug is that the app never says *why*, and that other screens behave as if it were a working day.
- **The run started at about 22:30 IST and crossed midnight.** The lab clock changes what screens *show*, not what actions decide (by design, `qa-clock.ts`). So the cover engine judged every period as "already begun", and after midnight some screens showed Wed 21 Oct. Run the next day during school hours, on a working day.
- The admin seat could not open `/settings`. That is the Smoke Lab rule (D-314: no smoke account manages settings or staff), not an app bug. The denied page still says “Only Admin can open this page” to an admin and shows the raw code `settings:manage`, which is a real wording problem for any refusal.
- No page error, server error or blocked outbound request was seen in any session. Nothing was sent to a parent; every register save had the WhatsApp switch turned off by hand.

## What held up

- **Cross-checks all passed.** The exam tracker matched every paper the teachers saved, number for number. No "Only me" note was visible to the academic coordinator. The absent lists on the coordinator's registers matched what eight class teachers saved.
- **Permissions.** No teacher reached any money screen. No role reached `/smoke`. Access-denied screens were clear and in the reader's language.
- **Money.** The Payment desk flow is clear and safe. The review shows child, class, SR, amount and mode before saving, a saved payment cannot be saved twice, and receipts, Day book and day-close preview agreed (₹3). A reversal request went from accountant to admin and back correctly.
- **The register on the normal path.** Everyone starts Present, rows are 70 px tall, it takes 7–8 taps, and unsaved taps survive Back and reload.
- **Speed.** Most screens loaded in 1.2–4.4 s. Exceptions: My class (11 s) and Grace (9.4 s).

## Patterns behind many findings

- **Effects that depend on inline callbacks run again on every render and steal focus or reset state. Overlays' focus-first effect is the confirmed case; any vx primitive with a callback in its effect deps can do the same.**
  Use a 'latest ref' for callbacks inside primitives (Sheet, Toast, Seg), and focus only on the open transition. Add an architecture test that greps src/vx/ui for useEffect deps containing onClose, onChange or onPick.
- **Client screens seeded from server props keep stale state after a soft navigation to the same route with a different ?class or ?day, and URL state is read once.**
  Key every vx screen component by its identity params (class, day, paper, student) in its page.tsx. Make useUrlState follow useSearchParams.
- **Success states are computed from the wrong source and say 'done' when it is not: the saved card counts local marks, 'cover arranged' counts days, the 0/0 ring is full, 'All 14 sent' ignores blanks, 'Nothing waiting' leaves out remarks, 'No cover needed' leaves out missed periods, and 'up to date' shows while a save is pending.**
  One rule: a green or Done state is drawn only from server-confirmed data, and it must name what is NOT done ('3 of 14 sent · 11 blank'). Give the vx ui a <Done done needed /> helper that turns warn when done<needed and grey when needed===0, and use it for rings, pills and toasts.
- **'Today' is assumed: wording hard-codes today, and the comparison uses the register's own day instead of the school's today.**
  Loaders return isToday computed from schoolToday(schoolNow(staff)). Every 'today' string becomes a dated pair when it is false, and absentAlert takes a past flag.
- **Two clocks: some reads use schoolNow(staff) (the lab clock), while others call schoolToday() or new Date() directly. Screens in one session therefore disagree, and cover is judged on the real clock.**
  Pass `now` from schoolNow(staff) through every loader and action that decides time-of-day, or at least every read. Grep for bare schoolToday() in the files listed.
- **Language leaks: 'hi' readers get English sub-lines through under(), dates are en-GB only, segments use tx() without a sub-line, the title shows the other language on purpose, and the EN/हि switch writes only en or hi.**
  under() returns null for 'hi'. Add a Hindi date/time formatter in vx/format. Use a three-state language control. Add a render test per teacher screen with language 'hi' that fails on Latin words outside names and codes.
- **Empty and closed states without a reason or a next step: holiday with no name, 'closed or not come yet', no class with no way to call anyone, 'check the spelling' when the teacher has no children, and a denied page with a raw permission code.**
  A shared <Why reason action/> empty-state contract: every empty or blocked card states the real reason in one plain sentence and offers one button (call the office, open the last open day, go to the right class).
- **Same-named children cannot be told apart outside the register: note picker, remarks chips (first names only), grace list, academic register.**
  Move tellApart (teach/data.ts:571) into a shared domain helper and use it in every child list and chip. Show full names on chips.
- **Jargon and placeholders shown to non-technical staff: 'Draft on this device', register, Sampark link, पुष्टि, प्रविष्टियाँ, submission, PENDING-SR-…, settings:manage, ELGA, NUR, Enter/A keyboard hints on a phone.**
  Add a banned-words list to tests (scan src/vx and src/messages for these words in user-facing pairs). Replace them with plain words: 'Kept on this phone' / 'फ़ोन में रखा है'; 'attendance' / 'हाज़िरी'; 'Nursery' / 'नर्सरी'. Hide internal codes.
- **Tap targets under 44 px on inline text-buttons and links.**
  Set a coarse-pointer minimum size on .tap in vx.css, and add a Playwright audit at 360 and 390 px.

## Making the next run better

Ideas, including lessons from this one:

1. **Plan on a working day, in school hours.** Have `open-run` refuse a holiday from the school calendar, and warn when the real clock is outside 07:00–15:00, because actions use the real clock.
2. **Seed what every role needs:** an open paper for every subject teacher (with an Exempt choice), a pending reversal, and an office task. Then no agent says "no open paper" (teacher11 could not do marks).
3. **Include the roles this run left out:** office, fee collectors and view-only. Office tasks were done by the admin here.
4. **A re-run after fixes**, with the same seats and personas. Mark each finding *verified* or *regressed* on `/smoke`, and only call a fix done when its re-run passes.
5. **Automatic checks for what agents found by hand.** A Hindi screen render test that fails on English words. A banned-jargon list (draft, submission, पुष्टि, प्रविष्टियाँ, PENDING-SR). A 44 px tap-target audit at 360 and 390 px. A "green only when done" check for rings, pills and toasts.

7. **Time each task end to end, not only page loads.** "From Today to saved attendance" is the number a teacher feels.
