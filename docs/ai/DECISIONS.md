## Claude voice format and Gemini model — 4 November 2026

- **D-414.** Claude answers Bolo in `claudeVoiceOutput` (`voice-schema.ts`): the same fields as `voiceSpec`, all required, with an empty string, 0, false or an empty list for "not said". `fromClaudeVoice` drops those, then `voiceSpec.validate` checks the answer as before, so the resolver and Gemini are unchanged. Why: Anthropic compiles each output schema into a grammar, and each optional field roughly doubles it (limits: 24 optional and 16 union fields per request; compile timeout 180 s). With `voiceSpec`'s 20 optional fields the first compile outlasted the 18 s Claude stage on every request, so Claude never answered a voice command and the grammar was never cached. `providers.ts` now takes `claude: { format, read, note }` in place of `claudeFormat`.
- **D-415.** `GEMINI_MODEL=gemini-3.5-flash-lite` for Production and Preview (Config type, set with `vercel env add`). No free-key model could be ranked because none answered; 3.5 Flash-Lite passed text and image on the paid key and is the cheapest current Flash ($0.30 in / $2.50 out per MTok). The paid key follows it (`GEMINI_MODEL_PAID` stays unset).
